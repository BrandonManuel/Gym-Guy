# Gym Guy

A pixel art typing game. Pick up the dumbbell, follow the arrow, and type as fast as you can!

## How to Download
1. Navigate to the [builds directory](https://github.com/BrandonManuel/Gym-Guy/tree/main/Builds)
2. Select either `Gym Guy.zip` or `Gym Guy Mac.zip` depending on your platform
3. Click the download button at the top right
   <img width="2202" height="239" alt="image" src="https://github.com/user-attachments/assets/6502e41c-d18a-4036-a250-3d7fda910415" />
4. Extract the zip file
5. Launch the executable


## How to Play

1. Walk up to the dumbbell and pick it up
2. Follow the arrow to the workout zone
3. Type the letters that appear on screen before the timer runs out
4. Each successful lift increases your score — see how high you can get!

## Controls

| Input | Action |
|-------|--------|
| `W A S D` | Move |
| `E` | Pick up dumbbell |
| `Letter Keys` | Type letters shown on screen |
| `Escape` | Pause |
| Mouse | Navigate menus |
